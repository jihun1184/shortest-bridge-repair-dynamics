# Exact local decision rule on the finite domain

Let K(Y,R) be the residual-signature multiset key defined in the article. The finite domain contains 117 realized keys.

- For 113 keys, the geometric predicate Gamma(Y,R) is identically false.
- The remaining four keys contain 293 classes. On these classes, Gamma(Y,R) holds exactly when a residual-chainable shortest endpoint frame is adjacency-saturated, i.e. every consecutive L1 gap in the oriented frame has length one.

The resulting classification is false on 37,018 classes and true on 40 classes. The complete 117-key table and the four mixed-key totals are included in this directory.
