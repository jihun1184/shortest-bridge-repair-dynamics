# Stabilization finite data

These machine-readable files contain the bounded finite objects used in the proof of the all-parameter stabilization theorem: the base quotient, representative geometry, connected- and isolated-satellite finite checks, the parametric reachability tree, and the complete k=9 closure summary.

The finite files provide bounded base facts. The extension to every k >= 6 is the structural argument in the main article, not an extrapolation from these data.
