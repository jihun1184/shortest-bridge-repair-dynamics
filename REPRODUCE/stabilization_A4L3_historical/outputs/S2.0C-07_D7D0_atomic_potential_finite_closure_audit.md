# C07-D7D0 — Atomic Potential and Finite-Closure Audit

## 1. Verdict

Under the frozen C07-D5 atomic semantics, the candidate potential

\[
\Phi(X)=|\operatorname{Comp}_6(X)|+\mathbf 1[has\_fail(X)]
\]

strictly decreases along every admissible atomic transition:

\[
\boxed{X\xrightarrow{\Delta}X'\Longrightarrow \Phi(X')<\Phi(X).}
\]

The result is **PROVED from the frozen definitions**. A separate finite
implementation regression passed on 986 states and 140,329 generated
transitions, with no counterexample.

Consequently, for every finite nonempty initial state \(X_0\), its complete
atomic reachable graph is a finite, acyclic, finite-depth graph. Every atomic
path has length at most

\[
\boxed{\Phi(X_0)-1.}
\]

Therefore exact atomic goal reachability, and hence exact atomic
unreachability for an individual finite state, is decidable by complete closure
enumeration under this frozen action language. This is a state-dependent
termination theorem; it is not a universal constant-depth theorem and does not
establish atomic completeness.

## 2. Audited frozen semantics

The implementation path was traced before attempting the proof.

### 2.1 N1 actions

`valid_single_add_repairs(X)` constructs candidates only from currently
disconnected Q2/Q3 masks and retains exactly those voxels \(v\) for which

\[
has\_fail(X\cup\{v\})=\mathrm{False}.
\]

If `has_fail(X)=False`, the bad-mask list and hence the N1 action set are empty.
Thus an N1 action can occur only at a defective state, and its successor is
Q2/Q3-valid by direct evaluation.

### 2.2 N2 actions

For every genuine unordered pair of distinct current 6-components,
`certificate_bridge_actions`:

1. computes all component endpoint pairs attaining minimum \(d_6\);
2. enumerates every coordinate-wise monotone shortest path;
3. forms the successor from the full path and current state;
4. discards the path whenever `has_fail(successor)` is true;
5. deduplicates the remaining nonempty addition sets.

Hence successor validity is not an external assumption: it is an explicit
membership condition of the frozen N2 action generator.

### 2.3 Atomic union

`atomic_actions(X)` deduplicates by the addition set and preserves both role
labels when an action is simultaneously N1 and N2. The proof below therefore
handles N1-only, N2-only, and dual-role actions without treating labels as
distinct transitions.

## 3. Symbolic proof

### Lemma D7D0.1 — N1 attachment

If \(\{v\}\in A_{N1}^{(1)}(X)\), then \(v\) is 6-adjacent to at least one voxel
of \(X\). Consequently,

\[
|\operatorname{Comp}_6(X\cup\{v\})|
\le |\operatorname{Comp}_6(X)|.
\]

**Proof.** By definition, \(v\) is drawn from a disconnected occupied Q2 or Q3
mask \(M\) of \(X\). Let \(S\) be the occupied mask vertices before the action.
The induced mask graph on \(S\) is disconnected. Because \(v\) is a valid
single repair, the same mask is not disconnected in \(X\cup\{v\}\); thus the
induced graph on \(S\cup\{v\}\) is connected. In particular, \(v\) is adjacent
in the Q2/Q3 hypercube graph to an element of \(S\). Mask-graph adjacency is
exactly facet adjacency of the corresponding voxels, hence 6-adjacency. Adding
an attached vertex cannot create a new global 6-component. \(\square\)

This lemma does not claim that every N1 action contracts components. It may
leave the global component count unchanged when locally separated mask pieces
are already connected outside the mask.

### Lemma D7D0.2 — N2 contraction and validity

If \(\Delta\in A_{N2}(X)\) and \(X'=X\cup\Delta\), then

\[
has\_fail(X')=\mathrm{False}
\quad\text{and}\quad
|\operatorname{Comp}_6(X')|
\le |\operatorname{Comp}_6(X)|-1.
\]

**Proof.** The action is generated from a shortest 6-path whose endpoints lie
in two distinct current components. The path union connects those components,
so their descendants coincide and the component count drops by at least one.
The generator retains the path only after directly checking that the successor
has no Q2/Q3 failure. \(\square\)

### Theorem D7D0.3 — Strict atomic descent

For every admissible atomic transition \(X\to X'\),
\(\Phi(X')<\Phi(X)\).

**Proof.**

- If the action has an N2 role, Lemma D7D0.2 gives a component decrease of at
  least one and a valid successor. If \(X\) is valid, \(\Phi\) drops by at least
  one; if \(X\) is defective, it drops by at least two.
- Otherwise the action is N1-only. Such an action exists only when \(X\) is
  defective. Its successor is valid, so the indicator drops from one to zero,
  while Lemma D7D0.1 says the component count does not increase. Therefore
  \(\Phi\) drops by at least one.

Dual-role actions are already covered by the stronger N2 case. \(\square\)

## 4. Finite-closure corollary

### Lemma D7D0.4 — Finite branching

For finite \(X\), \(A_{\mathrm{atom}}(X)\) is finite.

**Reason.** A finite state touches finitely many Q2/Q3 masks, so it has finitely
many N1 candidates. It has finitely many component pairs and endpoint pairs.
Each endpoint distance is finite and admits finitely many monotone step
orderings. Deduplication cannot increase this number.

### Corollary D7D0.5 — Finite contraction DAG

Let \(X_0\ne\varnothing\) be finite. Every successor is nonempty and valid, so
its potential is at least one. The strict integer descent theorem implies that
every atomic path from \(X_0\) has length at most \(\Phi(X_0)-1\). Combined with
finite branching, the complete reachable tree and its state-deduplicated graph
are finite. The graph is acyclic both by strict potential descent and by strict
addition-only state inclusion.

It follows that a breadth-first or depth-first enumeration of the entire
reachable closure terminates and exactly decides whether `Goal` occurs. A
completed closure with no goal is a valid finite-state atomic-unreachability
certificate. This corollary does not say that such enumeration is practically
small.
