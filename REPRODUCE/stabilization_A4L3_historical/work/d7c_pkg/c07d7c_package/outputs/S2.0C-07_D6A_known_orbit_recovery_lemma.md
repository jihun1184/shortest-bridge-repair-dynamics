# S2.0C-07 — C07-D6A Known-Orbit Exact Depth-2 Recovery Lemma

> **D6B1/2 후속 결과 (2026-08-20):** D6A theorem은 그대로 유지된다. Canonical
> orbit의 one-extra family에서는 no-dual candidate가 없었고, two-extra family의
> no-dual states는 3 isometry orbits로 quotient되어 depths `2,1,1`을 가졌다.
> Depth-2 orbit의 first action은 N1-only이므로 dual-role은 depth-2 recovery의
> 필요조건이 아니다. Depth≥3/atomic-unreachable은 발견되지 않았고 D6B는 OPEN이다.

## 2. Group action과 orbit

`G`를 lattice translations와 signed coordinate permutations가 생성하는 군으로
둔다.

\[
G=\mathbb Z^3\rtimes B_3,
\]

여기서 `B_3`는 coordinate permutation 6개와 sign choices 8개로 이루어진
48원소 hyperoctahedral group이다. `g∈G`는 voxel set과 addition set에
pointwise로 작용한다.

Canonical D3E witness를

\[
\begin{aligned}
X_0=\{&(-3,-1,-1),(-1,0,0),\\
      &(0,-1,-1),(0,-1,0),(0,2,-1)\}
\end{aligned}
\]

로 두고 known orbit를

\[
\mathcal O_{D3E}=\{gX_0:g\in G\}
\]

로 정의한다. D5의 24개 full counterexamples는 이 orbit의 유한 search-window
members다.

## 3. Theorem

### Theorem D6A — Known-orbit exact atomic depth-2 recovery

모든 `X∈O_D3E`에 대해

\[
d_{\mathrm{plan}}(X)=2.
\]

더 구체적으로, 어떤

\[
\Delta_1\in A_{N1}^{(1)}(X)\cap A_{N2}(X)
\]

와

\[
\Delta_2\in A_{N2}(X\cup\Delta_1)
\]

가 존재하여

\[
Goal(X\cup\Delta_1\cup\Delta_2)
\]

가 성립한다. 반면 `A_atom(X)`의 어떤 action도 한 transition만으로 goal에
도달하지 못한다.

여기서 depth 2는 voxel 두 개가 아니라 **두 atomic actions**를 뜻한다.
`Delta_2`는 여러 voxel을 포함하는 N2 bridge action이다.

## 4. Canonical upper bound certificate

`X_0`의 네 6-components를

\[
\begin{aligned}
C_A&=\{(-3,-1,-1)\},\\
C_B&=\{(-1,0,0)\},\\
C_C&=\{(0,-1,-1),(0,-1,0)\},\\
C_D&=\{(0,2,-1)\}
\end{aligned}
\]

로 둔다.

### 4.1 First action

\[
\Delta_1=\{(-1,-1,0)\}=\{v_1\}.
\]

`v_1`은 `C_B`의 `(-1,0,0)`과 `C_C`의 `(0,-1,0)` 사이의 길이 2
6-path에서 유일한 interior voxel이다.

\[
(-1,0,0)\to(-1,-1,0)\to(0,-1,0).
\]

따라서 `Delta_1∈A_N2(X_0)`. 동시에 `X_0∪Delta_1`은 Q2/Q3-valid이므로
`Delta_1∈A_N1^(1)(X_0)`다. 즉 첫 action은 dual-role이다.

첫 successor의 component 수는 `4→3`이다.

### 4.2 Second action

다음 addition set을 택한다.

\[
\begin{aligned}
\Delta_2=\{&(-3,0,-1),(-2,0,-1),(-1,0,-1),\\
            &(0,0,-1),(0,1,-1)\}.
\end{aligned}
\]

이는 `C_A`의 `(-3,-1,-1)`에서 `C_D`의 `(0,2,-1)`까지의 다음 6-path의
interior다.

\[
\begin{aligned}
(-3,-1,-1)&\to(-3,0,-1)\to(-2,0,-1)\\
&\to(-1,0,-1)\to(0,0,-1)\\
&\to(0,1,-1)\to(0,2,-1).
\end{aligned}
\]

Endpoint distance는

\[
\|(-3,-1,-1)-(0,2,-1)\|_1=6
\]

이고 interior voxel은 5개이므로 `d6-1` optimal bridge다.
또한 bridge voxel `(-1,0,-1)`은 `C_B`에, `(0,0,-1)`은 `C_C`에
6-adjacent하다. 따라서 이 path는 `C_A`, 중간 descendant, `C_D`를 모두
흡수하여 component 수를 `3→1`로 만든다.

최종 상태

\[
X_G=X_0\cup\Delta_1\cup\Delta_2
\]

는 Q2/Q3-valid이고 6-connected이므로 `Goal(X_G)`다.

## 5. Canonical compatibility certificate

Compatibility는 frozen Q2/Q3 mask definition으로 finite audit했다. 각 edge/vertex
mask에서 occupied induced hypercube graph가 connected인지 확인했다.

| state | nontrivial masks | occupancy signature | disconnected masks |
|---|---:|---|---:|
| `X0∪Delta1` | 18 | Q2: `8×size2, 2×size3`; Q3: `5×size2, 2×size3, 1×size4` | 0 |
| `XG` | 62 | Q2: `26×size2, 9×size3`; Q3: `16×size2, 8×size3, 2×size4, 1×size6` | 0 |

이 표는 search 결과가 아니라 두 명시적 finite states의 local proof certificate다.
패키지 JSON에는 80개 nontrivial mask의 positions, occupancy labels, connectivity
verdict가 모두 들어 있다.

## 6. Canonical lower bound

`A_atom(X_0)`를 resulting addition set으로 전수하면 정확히 8개다.

| action class | count | addition cardinality | successor components | one-step goal |
|---|---:|---:|---:|---:|
| N2-only | 6 | 3 | 2 | 0 |
| dual-role `N1∩N2` | 2 | 1 | 3 | 0 |

모든 successor는 Q2/Q3-valid이지만 component가 2개 또는 3개 남는다. 따라서

\[
\forall\Delta\in A_{atom}(X_0),
\neg Goal(X_0\cup\Delta).
\]

즉 `d_plan(X_0)≥2`. §4의 explicit plan으로 `d_plan(X_0)≤2`이므로

\[
d_{\mathrm{plan}}(X_0)=2.
\]

이다. 전체 shortest action-set sequences는 8개지만 theorem에는 그중 명시적
한 개만 필요하다.

## 7. Equivariance lemmas

### Lemma 7.1 — Certificate equivariance

모든 `g∈G`에 대해 6-adjacency와 connected components가 보존된다.

\[
\operatorname{Comp}_6(gX)=g\operatorname{Comp}_6(X).
\]

따라서 genuine N2 component certificates와 addition-only descendants도
`g`와 commute한다.

### Lemma 7.2 — Compatibility equivariance

Translations와 signed coordinate permutations는 edge/vertex neighborhoods를
같은 종류의 Q2/Q3 mask로 보내고, occupied hypercube induced graph의 adjacency를
보존한다. 따라서

\[
has\_fail(gX)=has\_fail(X).
\]

### Lemma 7.3 — Action equivariance

`g`는 L1 distance와 shortest 6-path를 보존한다. Signed permutation은 어떤
coordinate-wise monotone shortest path를 transformed endpoints 사이의
coordinate-wise monotone shortest path로 보낸다. 그러므로

\[
gA_{N1}^{(1)}(X)=A_{N1}^{(1)}(gX),
\]

\[
gA_{N2}(X)=A_{N2}(gX),
\]

및

\[
gA_{atom}(X)=A_{atom}(gX)
\]

가 role labels까지 포함해 성립한다.

### Lemma 7.4 — Goal equivariance

Q2/Q3 validity와 component 수가 보존되므로

\[
Goal(gX)\iff Goal(X).
\]

### Theorem의 orbit 확장

`X=gX_0`라 하자. Canonical plan을

\[
g\Delta_1,\quad g\Delta_2
\]

로 보내면 Lemma 7.3에 의해 각각 transformed state의 admissible atomic
actions이고 Lemma 7.4에 의해 최종 state는 goal이다. 따라서 depth는 2 이하이다.
반대로 canonical 8 actions가 `g` 아래 transformed action set 전체와 일대일
대응하고 어느 것도 goal이 아니므로 depth는 1이 아니다. 따라서 모든 orbit
member의 exact depth는 2다.

추가로 canonical stabilizer 안에는

```text
permutation = (1,0,2)
signs       = (-1,-1,+1)
translation = (-1,-1,0)
```

인 symmetry가 있으며 `v1`을 `v2`로 보낸다. 따라서 두 dual-role recovery
branches도 동일한 structural mechanism이다.

## 8. Verification scope

구조적 equivariance proof와 별도로 regression은 다음을 실행했다.

- signed-axis elements 48개,

각 instance에서 canonical action-role map의 image가 transformed state에서

확인했다. Arbitrary translation에 대한 주장은 이 두 sample 때문이 아니라
Lemmas 7.1–7.4의 translation equivariance에서 따른다.

## 9. 주장 수준 구분

### 증명된 사실

- Known D3E orbit의 모든 member는 exact atomic planning depth 2다.
- 첫 action은 dual-role, 두 번째 action은 N2-only인 plan이 존재한다.
- Canonical state에는 one-action goal transition이 없다.
- `v1`, `v2` branches는 internal symmetry로 대응한다.

### Machine-checked finite base certificate

- Canonical initial atomic actions 8개 전체.
- 두 explicit successor의 Q2/Q3 nontrivial masks 18개와 62개 전체.
- Canonical component counts `4→3→1`.
- 96 transformed regression instances.

### 아직 주장하지 않는 것

- D3E known orbit 밖의 greedy counterexamples가 depth 2라는 주장.
- Universal atomic completeness.
- Universal finite look-ahead bound.
- 24-member search output이 전체 minimal-counterexample classification이라는 주장.

1. **논리 검증:** Upper bound의 explicit plan과 lower bound의 full initial-action

3. **출처 적절성:** D5의 frozen action semantics와 D3E의 source-aligned N2

4. **언어적 매끄러움:** Two-action depth와 two-voxel addition을 구분하고, finite

5. **윤리적 경계:** Known orbit theorem을 universal planning theorem으로 확대하지
   않았고, sampled translations를 일반 equivariance proof로 오인하지 않았다.
