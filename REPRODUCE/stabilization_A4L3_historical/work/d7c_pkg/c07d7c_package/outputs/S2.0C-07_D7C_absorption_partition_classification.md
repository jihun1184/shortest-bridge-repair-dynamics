# C07-D7C — Absorption-partition classification

## 1. Verdict

The declared 150-state D7B family admits an exact finite structural classifier:

\[
\boxed{
d_{\mathrm{plan}}(X)=2
\iff
\exists v\in A_{N1}^{(1)}(X),\ \exists\Delta\in A_{N2}(X\cup\{v\})
:\ |\mathcal P_{X\cup\{v\}}(\Delta)|=1.
}
\]

The equivalence is correct for all 150 admitted states. The 19 depth-two states have a compatible full-absorption N2 action after at least one N1 choice. In all 131 depth-three states, full absorption is already absent among the raw shortest monotone orderings, before compatibility filtering.

Thus, within this family, the depth split is controlled by the existence of a geometrically full-absorbing shortest bridge. No state belongs to the intermediate class “raw full absorption exists, but compatibility deletes every such ordering.”

This is an exact finite-family theorem, not a universal planning-depth theorem.

## 2. Frozen partition semantics

For a state \(X\), let

\[
\mathcal C(X)=\{C_1,\ldots,C_m\}
\]

be its 6-components. An addition-only action \(\Delta\) gives every old component a unique descendant \(D_\Delta(C_i)\) in \(X\cup\Delta\). Define

\[
C_i\sim_\Delta C_j
\iff
D_\Delta(C_i)=D_\Delta(C_j).
\]

The **absorption partition** is

\[
\boxed{
\mathcal P_X(\Delta)=\mathcal C(X)/{\sim_\Delta}.
}
\]

Its derived scalars are

\[
\rho_X(\Delta)=\max_{B\in\mathcal P_X(\Delta)}|B|
\]

and

\[
\gamma_X(\Delta)=|\mathcal C(X)|-|\mathcal P_X(\Delta)|.
\]

Here \(\rho\) is the largest number of old components absorbed into one descendant, while \(\gamma\) is the total component contraction.

## 3. One-nontrivial-block property

The frozen N2 action generator constructs an addition set from one monotone shortest path joining endpoints in a genuine component pair. Every old component touched by that path or its added voxels is connected through the same path union. Hence all touched old components enter one descendant. Untouched components remain separate.

Therefore an N2 action produces exactly one nontrivial partition block; every other block is a singleton. In particular,

\[
\boxed{\gamma_X(\Delta)=\rho_X(\Delta)-1}
\]

for these N2 actions.

This conclusion was also checked directly over the entire census:

| Object enumerated | Count | Nontrivial blocks per partition |
|---|---:|---:|
| Raw shortest monotone orderings | 273,921 | exactly 1 |
| Distinct compatible N2 actions | 109,927 | exactly 1 |

The empirical census audits the implementation; the path-connectivity argument supplies the structural reason.

## 4. Why the classifier is exact in this family

Every admitted D7B state has exactly two initial atomic actions, and both are N1-only. After either N1 action, the state is locally valid and has five 6-components. Consequently, any length-two goal plan must have the form

\[
N1\text{-only}\longrightarrow N2\text{-only}.
\]

The second action reaches `Goal` exactly when all five components of the N1 successor have one common descendant, equivalently

\[
|\mathcal P_Y(\Delta)|=1
\quad\Longleftrightarrow\quad
\rho_Y(\Delta)=5.
\]

Thus the logical form of the classifier follows from the frozen action semantics. The computation determines which of the 150 states satisfy its existential geometric condition.

The result is:

| Exact depth | States | Maximum compatible \(\rho\) |
|---:|---:|---:|
| 2 | 19 | 5 |
| 3 | 34 | 3 |
| 3 | 97 | 4 |

Hence the classifier is correct for

\[
150/150
\]

states, with zero false positives and zero false negatives.

## 5. Raw geometry versus compatibility

Each of the 300 N1 successors was audited twice:

1. over every raw monotone ordering joining a \(d_6\)-minimizing endpoint pair;
2. over the distinct actions remaining after Q2/Q3 compatibility filtering and addition-set deduplication.

The state-level classification is:

| Full-absorption class | Depth 2 | Depth 3 | Total |
|---|---:|---:|---:|
| Compatible full absorption exists | 19 | 0 | 19 |
| Raw full absorption exists, but all are incompatible | 0 | 0 | 0 |
| Raw geometry forbids full absorption | 0 | 131 | 131 |

Therefore the depth-three obstruction throughout this family is geometric. Compatibility removes many individual shortest orderings, but it never changes a raw-full state into a no-full state in this census.

This strengthens the D7A observation: the canonical D6C witness is not an isolated example of a compatibility-independent absorption obstruction. The same raw-geometric mechanism class covers all 131 depth-three satellite extensions in the declared family.

## 6. Is scalar rank sufficient?

For the binary depth-two/depth-three classification in this fixed five-component family, yes:

\[
d_{\mathrm{plan}}(X)=2
\iff
\max_{v,\Delta}\rho_{X\cup\{v\}}(\Delta)=5.
\]

However, \(\rho\) does not retain which components are absorbed. After mapping both N1 successors back to the five original component identities, the number of distinct maximal absorbed subsets per state is:

| Depth | Maximum \(\rho\) | Distinct maximal subsets | States |
|---:|---:|---:|---:|
| 2 | 5 | 1 | 19 |
| 3 | 3 | 3 | 4 |
| 3 | 3 | 4 | 19 |
| 3 | 3 | 5 | 11 |
| 3 | 4 | 1 | 39 |
| 3 | 4 | 2 | 58 |

Thus states with the same scalar \(\rho\) can admit different families of absorbed component subsets. This identity information does not further split depth two from depth three here, but it determines which residual components survive and therefore which partitions can occur at the next planning step.

The correct conclusion is:

\[
\boxed{
\rho\text{ is sufficient for this immediate full-absorption classifier,}
\quad
\mathcal P\text{ is required for transition-level mechanism analysis.}
}
\]

## 7. Consequence for persistent-obstruction research

A static bound on \(\rho_X\) at the initial state cannot establish an unbounded-depth family. After one contraction, the geometry changes and a later action may acquire much larger rank. The appropriate target is a bound persistent over reachable states:

\[
\forall Y\in Reach(X),\quad
\forall\Delta\in A_{N2}(Y),\quad
\rho_Y(\Delta)\le r.
\]

If such a fixed \(r\) holds while the initial component count \(m\) grows, then every N2 action contracts at most \(r-1\) components and

\[
d_{N2}(X)
\ge
\left\lceil\frac{m-1}{r-1}\right\rceil.
\]

The inequality is conditional on persistence along every relevant reachable branch. D7C does not establish that condition. It identifies the partition data needed to test it.

The next checkpoint should therefore be **C07-D7D — Persistent Absorption-Obstruction Attack**: search for a growing family whose reachable partition transitions preserve a fixed rank bound, or identify a geometric reason why high-rank shortcuts must eventually appear.

## 8. ELI5 intuition

Suppose five islands must become one. A bridge action does more than say “I joined four islands”; it says exactly *which* four were joined and which island was left out. The number four is enough to know that the job is not finished. But to plan the next bridge, one must know the identity of the island left behind. Absorption rank remembers the number; absorption partition remembers the whole grouping.
