# D7D2-A1.2 / A1.3 — Contact-Accumulator Sufficiency Lemma and Threshold-Quotient Exactness

## 1. Setup

Fix a current reachable state \(Y\) (any state in any closure, not just a
root) and its component decomposition \(\operatorname{Comp}_6(Y) =
\{C_0,\dots,C_{n-1}\}\), \(n\le5\). Fix a certificate \((\text{left},
\text{right})\) with \(\text{left}=C_i\), \(\text{right}=C_j\), and one
endpoint pair \((s,t)\) attaining the minimum \(d_6\) between them. Let
\(K = Y\) (the full current state; this is exactly what
`component_bridge_exists` passes as `background`). Let
\(\text{Other} = \{C_l : l\ne i,j\}\), \(|\text{Other}|\le3\).

For a monotone path \(P = (p_0{=}s, p_1,\dots,p_m{=}t)\), define the contact
set
\[
T(P) = \{\, l : C_l\in\text{Other},\ \exists\, p_r\in P\setminus\{s,t\}
\text{ with } p_r \text{ 6-adjacent to some point of } C_l \,\}.
\]

**Fact (checked directly against the code, Section 1 files):** for any
successor state \(Y'=Y\cup(P\setminus Y)\) produced by a compatible path
\(P\), \(\operatorname{Comp}_6(Y')\) merges exactly \(C_i\), \(C_j\), and
every \(C_l\) with \(l\in T(P)\) into one component, and leaves all other
components of \(Y\) unchanged. (This was independently confirmed
computationally, not merely asserted: across 2,656 real bridge actions the
identity \(\rho(P) = 2+|T(P)|\) held with zero exceptions — see
`verify_contact_automaton.py`, check 1.) So \(\rho(P)=2+|T(P)|\) exactly,
and the question "\(\exists P:\rho(P)\ge4\)" is exactly
"\(\exists P: |T(P)|\ge2\)".

## 2. Lemma (Contact-Accumulator Sufficiency)

**Claim.** Fix \(K\), \(t\), and the fixed background partition into
\(\{C_0,\dots,C_{n-1}\}\) (hence into `left`, `right`, `Other`). Let
\(\pi_1=(p_0,\dots,p_r)\) and \(\pi_2=(p_0'\dots,p_r')\) be two compatible
partial-path prefixes (i.e. `compressed_transition` never returned `DEAD`
along either) that reach the **same compressed state** \((p,\sigma)\) —
i.e. \(p_r=p_r'=p\) and the trailing \(\sigma\) computed by `sigma_update`
along each prefix is identical. Then for every candidate next voxel \(q\),
\[
\texttt{compressed\_transition}(K,K_{\text{masks}},t,p,\sigma,q)
\]
returns the same outcome (DEAD, or the same \((q,\sigma')\)) regardless of
whether it is invoked following \(\pi_1\) or \(\pi_2\).

**Proof.** Inspect the actual signature and body of `compressed_transition`
(`compressed_decider.py`, lines 102–168, reproduced in this package
unmodified). Its only arguments are `(K, K_masks, t, p, sigma, q)`. Every
computation inside it — `sigma_update`, `sigma_points`, `masks_touching`,
`is_active`, `is_disconnected`, the occupancy sets built from
`c in K or c in bridge_pts` — is a function purely of these six arguments,
via **set membership tests** against `K` and against `bridge_pts =
{p,q} ∪ sigma_points(p,sigma)`. Nowhere does the function read any
partition, labeling, or identity structure of `K` into components; `K` is
used only as an unlabeled point set. Since \(\pi_1,\pi_2\) share the same
\((p,\sigma)\) and the same fixed \(K,t\), the six arguments to
`compressed_transition` are identical for both, so — being a pure function
of its arguments (no hidden state, no history beyond what `sigma` already
encodes) — its output is identical. Likewise `successors(p,t)` (the
candidate-\(q\) generator) depends only on \(p,t\), so both prefixes offer
the same set of candidate continuations. \(\blacksquare\)

**Corollary (the actual Sufficiency Lemma needed).** Define the
contact-accumulator update
\[
T' = T \cup \{\, l : C_l\in\text{Other},\ q \text{ 6-adjacent to } C_l\,\}.
\]
Since (by the Lemma) the set of legal continuations from \((p,\sigma)\) is
independent of how \((p,\sigma)\) was reached, and \(T'\) is computed from
\(q\) alone (not from \(\pi_1\) or \(\pi_2\) as a whole), the **maximum**
\(|T(P)|\) achievable by any full completion of a prefix reaching
\((p,\sigma)\) with accumulated set \(T\) equals \(|T| +
f(p,\sigma)\), where \(f(p,\sigma)\) is a fixed quantity (the best
achievable *additional* new-id count from \((p,\sigma)\) onward) that does
not depend on \(T\) or on which prefix reached \((p,\sigma)\) — **provided**
no id in \(T\) can be "re-earned": since \(T\) is a set (not a counter),
revisiting an already-accumulated id contributes nothing new, so the true
quantity that must be carried forward is not just \(|T|\) but the *set*
\(T\) itself, to correctly suppress double-counting of a repeated id. This
is exactly why `contact_automaton.py` propagates the actual set/id (or the
saturated marker), not a bare integer — see §3.

This gives soundness of the product automaton \((p,\sigma,T)\): merging
different histories that reach the same \((p,\sigma)\) is valid as long as
we retain, per reached state, the **set of distinct \(T\)-values** seen
(not just their sizes), because different specific \(T\) values can lead to
different future outcomes precisely when a future step touches an id
already in one history's \(T\) but not the other's.

## 3. Corollary (Threshold-Quotient Exactness for \(\rho\ge4\))

For the specific question \(\exists P: |T(P)|\ge2\), it is **not** sound to
quotient \(T\) down to a bare cardinality-2 saturating counter without
remembering identity, because a future step touching the *same* id already
in \(T\) must not increment a count-based state. It **is** sound to
quotient \(T\) to
\[
A \in \{\,\text{None},\ \ell\ (\ell\in\text{Other}),\ \mathrm{SAT}\,\}
\]
with update
\[
\mathrm{promote}(A,\text{touched}) =
\begin{cases}
\mathrm{SAT} & A=\mathrm{SAT},\ \text{or } |\text{touched}|\ge2,\\
\mathrm{SAT} & A=\ell,\ \ell\notin\text{touched},\ \text{touched}\ne\varnothing,\\
\ell' & A=\text{None},\ \text{touched}=\{\ell'\},\\
A & \text{otherwise (touched}=\varnothing\text{, or touched}=\{A\}),
\end{cases}
\]
because this update is exactly the pushforward of the true set-valued update
\(T\mapsto T\cup\text{touched}\) under the quotient map \(q(T) = \text{None}\)
if \(T=\varnothing\), \(q(T)=\ell\) if \(T=\{\ell\}\), \(q(T)=\mathrm{SAT}\)
if \(|T|\ge2\) — i.e. \(q(T\cup\text{touched}) =
\mathrm{promote}(q(T),\text{touched})\) for every \(T,\text{touched}\)
(direct case check, all four cases above). Since the quotient map commutes
with the update, and the DP only ever needs to know, at \(t\), whether
\(|T|\ge2\) was reached, tracking \(A\) instead of the full set \(T\) loses
no information relevant to the \(\rho\ge4\) question. This is exactly what
`contact_automaton.py`'s `promote()` implements (§ code, not re-derived
here).

**State-space bound.** \(|\{\text{None}\}\cup\text{Other}\cup\{\mathrm{SAT}\}|
= |\text{Other}|+2 \le 5\) (since \(|\text{Other}|\le3\) for a 5-component
family), independent of \(k\), path length, or geometry. Combined with the
existing \((p,\sigma)\) state bound from the frozen decider, the whole
product automaton's state space is bounded by a constant times the
original decider's, not by anything growing with the ray parameter \(k\).
This matches the observed near-linear (not combinatorial) runtime growth in
§ ray-extension results.

## 4. What remains open

- This proof is about **one certificate at one fixed state \(Y\)**. It does
  not by itself extend to a full reachable closure, where \(Y\) itself
  changes from state to state (D7D2-A2's job, not this note's).
- The Lemma and Corollary above are proved directly from the code's
  documented behavior in this session, cross-checked against 2,656 brute
  force actions (§1) and 18 full root-vs-automaton comparisons (previous
  checkpoint). They are not claimed to be a restatement of the unavailable
  `THEOREMS_C06D.md`; they stand on their own from the code as written.
