## 2. What changed and why it is valid

The prior checkpoint (`S2.0C-07_D7D1_partial_persistent_absorption_checkpoint.md`)
left 28 roots (14 orbits: 302, 316, 318, 320, 322, 329, 331, 333, 335, 337,
342, 344, 345, 347) uncomputed because full closures are expensive — the
largest previously-completed closure alone had 693,229 states.

These 28 roots did not need full closures to be classified. Two already-
available facts combine into a shortcut:

1. **D7D0 Lemma D7D0.2** (already proved, unchanged): every N2 action
   strictly decreases the current 6-component count.
2. **A structural bound on \(\rho\)**: at any state \(Z\), \(\rho_Z(\Delta)\)
   — the number of root-identity partition blocks an action merges — cannot
   exceed \(|\operatorname{Comp}_6(Z)|\), since a partition block is assigned
   per current component.

Every root \(Y\) has exactly 5 components (frozen D7B/D7D1 construction).
Enumerating only the actions available at \(Y\) itself (root layer, depth 0
— not the descendant closure) for all 28 roots gives:

```text
root-layer N2 actions enumerated     25,528
rho histogram                        {2: 9058, 3: 10822, 4: 5648}
roots with root-layer max_rho = 4    28 / 28
roots with root-layer max_rho < 4     0 / 28
```

Since every root already realizes \(\rho=4\), \(R^*(Y)\ge4\). Since every
descendant of \(Y\) has \(\le4\) components (fact 1) and every action's
\(\rho\) is bounded by the current component count (fact 2), no descendant
action can exceed \(\rho=4\) either. Hence \(R^*(Y)=4\) exactly for all 28
roots, established without enumerating a single descendant state.

Full derivation: `shortcut_theorem.md` in this folder.
Reproducible check: `verify_shortcut.py` in this folder (recomputes from the
frozen source, not from any cached table; independently re-run in this
session with matching output).
