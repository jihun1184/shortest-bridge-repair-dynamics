# D7D2-A4.2 — Diagnose Failure of Total Contraction

## Per-class breakdown of the 2,738 "not_in_lo" states (k=7 -> k=6)

```text
Total exact behavioral classes: 53
Classes with ALL states landing correctly ("only good"):  48
Classes with a MIX of landing and non-landing states:      5
Classes where NO state lands correctly ("only bad"):        0
```

The 5 mixed classes account for exactly the 2,738 failures:

```text
class A: good=579,   bad=111  (16.1% bad)
class B: good=2282,  bad=523  (18.6% bad)
class C: good=12672, bad=2030 (13.8% bad)
class D: good=452,   bad=37   (7.6% bad)
class E: good=160,   bad=37   (18.8% bad)
sum of bad = 111+523+2030+37+37 = 2,738  (matches exactly)
```

## The key fact: `n_only_bad = 0`

Every one of the 53 classes has at least one state (in fact, hundreds to
thousands) for which `thin_tail_contract` lands correctly in k=6's
closure with the right class. Combined with the earlier representative-
level result (53/53), this means: **whether a given concrete state's
contraction "lands" is not a property of its behavioral class — it is an
accident of which specific voxel realization was picked.** Two states
that are exactly bisimulation-equivalent (same class, same future
behavior in every observable sense already checked) can differ in whether
this one concrete geometric operation happens to produce a valid k=6
state.

This directly confirms the point raised before running this diagnosis:
**`thin_tail_contract` landing-success is not a class invariant.**
Chasing a *total* concrete map `Reach(X_{k+1}) -> Reach(X_k)` was a
stronger requirement than the actual goal
(`Reach(X_{k+1})/~_b ≅ Reach(X_k)/~_b`) needs.

## Revised strategy (adopted)

Drop the total-map requirement. The relevant lemma is now:

> **Class Representative Lemma.** For every `k ≥ 6` and every one of the
> 53 exact behavioral classes `C`, there exists at least one
> representative `r_k(C) ∈ Reach(X_k)`, and `thin_tail_contract` maps
> `r_{k+1}(C)` to a state in the same class `C` at level `k`.

This is **already established** by the existing results:
- 53/53 representative-level match, confirmed independently on two pairs
  (k=7→6 and k=8→7, identical rule).
- 0 transition mismatches whenever the map lands correctly (established
  in the A4.1 all-state check).
- `n_only_bad = 0` here confirms a valid representative always exists in
  every class at every k tested, so `r_k(C)` is never vacuous.

What remains for A4-L3 is **not** "make the map total" but: show that the
53-class labeled transition structure among representatives
(`C --rho--> D`) is itself preserved going from `k` to `k+1` — which is
exactly the `Q_6 = Q_7 = Q_8` canonical-key equality already established
in D7D2-A3.2, now with a concrete (if partial/representative-only)
witness map connecting them, rather than an unexplained numerical
coincidence.

## Claim boundary

- This diagnosis explains *why* the total map fails (12.5% of concrete
  states are non-canonical accidents, not counterexamples to the
  quotient claim) — it does not itself prove `Q_k ≅ Q_{k_0}` for all
  `k ≥ k_0`. That induction (A4-L3 and beyond) is still open.
- The 5 mixed classes' bad-fraction (7.6%–18.8%) has not been further
  explained (e.g. what geometric feature distinguishes a good vs bad
  state within the same class) — this was not required once the
  representative-only strategy was adopted, per the plan, but is noted
  as unexplored rather than resolved.
