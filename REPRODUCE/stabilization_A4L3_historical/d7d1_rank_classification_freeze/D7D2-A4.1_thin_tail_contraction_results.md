# D7D2-A4.1 — Intrinsic Thin-Tail Contraction: consolidated results

## Reproducibility gap fixed first

The previous `a4_induction_diff.py` in the package only contained the
rejected blanket-shift map (0/53), even though the write-up reported the
component-aware 52/53 result — that result had only been run inline in an
interactive session and never saved to the script. This has been fixed:
`a4_induction_diff.py` now defines and tests all three maps in the order
they were actually tried (`blanket_shift`, `component_shift`,
`thin_tail_contract`), so the full history is reproducible from this one
file.

## The new map

`thin_tail_contract`: starting at the satellite point, walk toward the
core following the maximal **straight** run (constant y,z, unit x-steps,
exactly one point per x-slice) of the satellite's current component. Stop
at the innermost unit of that run (the point closest to the core / to any
thickened structure). Remove that unit and shift everything with
`x <= (that unit's x)` by `+1`. A thickened patch anywhere else in the
component (like the 5-point Q2/Q3 repair cluster that broke the earlier
`component_shift` map) is never touched, because the run stops before
reaching it.

## Representative-level results (step 1 + 2 of the agreed plan)

```text

```

**Identical pattern on both pairs, with the same single rule.** This is
real, mechanical, reproducible evidence for the induction map — not tuned
per-pair.

## All-state check (step 3 + 4 of the agreed plan) — a real gap found

Per the roadmap, the map was then tested on **every** state of k=7's
closure (not just the 53 representatives), checking: does the contracted
state exist in k=6's closure at all, does it land in the same exact
behavioral class, and do all of its rho-labeled transitions correspond?

```text
k=7 -> k=6, all 21,963 states:
  not landing in k=6's closure at all:  2,738 / 21,963  (12.5%)
  landing but wrong class:                  4 / 19,225  (0.02% of those that landed)
  landing, right class, transition mismatch: 0 / 19,221
```

**Honest reading:** the map is essentially exact (53/53, 0 class
mismatches among states that land correctly, 0 transition mismatches)
*when it lands at all*, but it fails to land in the target closure for
about 1 in 8 states of the full k=7 closure. This means
`thin_tail_contract` is not yet a total map on the full reachable set —
it is currently validated only as an excellent *representative-selection*
map (one state per class), not as a map defined and correct on every
state. The 53-representative match is real and useful evidence for the
existence of a quotient isomorphism `Q_7 ≅ Q_6`, but it does not by
itself establish that this specific map is the one witnessing it at the
full-state level.

## What this does and doesn't establish

- Strong, reproducible evidence (now saved in code, not just narration)
  that `Q_6 ≅ Q_7 ≅ Q_8` via a concrete, geometrically meaningful
  contraction rule at the representative level, confirmed on two
  independent pairs.
- Does **not** establish a full state-level (or even a total,
  everywhere-defined) map witnessing that isomorphism — per the prior
  message's own point, this was never required (many-to-one is fine), but
  the current map specifically has a real 12.5% "doesn't land anywhere in
  the target closure" gap that needs its own explanation before A4-L1/L2
  can be written as a clean per-action correspondence lemma.
- A4-L3 (bisimulation preservation) and the induction step have not been
  attempted.
