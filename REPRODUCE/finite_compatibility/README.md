# Finite compatibility reproduction (Appendix B precursor)

This directory contains the code and reference data for the finite compatibility calculations.

## Provenance

- Every file's SHA-256 was recomputed against the release's own
  `UPSTREAM_MANIFEST.json` (25/25 files matched) before any script was
  run.
- `UPSTREAM_README.md`, `UPSTREAM_MANIFEST.json`, `CONTENTS.txt`, and
  `LICENSE` are the release's own files, renamed only where needed to
  avoid clashing with this Supplement's own `README.md`.

## Reproduction scripts

The following scripts reproduce the finite compatibility calculations:

```bash
cd scripts
python3 depth_histogram.py
python3 bridge_lemma.py
python3 disjointness_L3_L5.py
python3 disjointness_L4.py
python3 section6_1_split.py
python3 walk_counts.py
```

The scripts reproduce the finite compatibility quantities summarized below:

| Script | Result obtained here |
|---|---|
| `depth_histogram.py` | 76 orbits / 528 pairs; depths 64,6,2,4; max 3 |
| `bridge_lemma.py` | 12 PASS / 0 FAIL |
| `disjointness_L3_L5.py` | L3: 3/3, L5: 12/12, 0 leaks |
| `disjointness_L4.py` | L4: 6/6, 0 leaks |
| `section6_1_split.py` | 27 False / 9 True, both classes uniform |
| `walk_counts.py` | L3=36, L4=108, L5=324; exact reference equality |

## Verification-strength caveat (from the upstream README, preserved here)

Reference equality against the frozen `reference_results/` files is an
**executable consistency check**, not an independent proof of frozen-
reference completeness for `L=4` or `L=5`. `L=3` alone is fully
independently reconstructed by exhaustive search. The 76-orbit `L=5`
classification is itself a frozen input (traced in `CONTENTS.txt` to a
named source archive and checksum), not freshly regenerated by this
package. See `../../S1_FINITE_COMPATIBILITY/SUPPLEMENTARY_NOTE.md`,
Section 2, for the per-`L` breakdown.

## Requirements

Python ≥3.9, standard library only (confirmed: ran under Python 3.12.3 in
the standard library).
